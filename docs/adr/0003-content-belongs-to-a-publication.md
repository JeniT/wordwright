# Ideas, notes and lists of articles always belong to a publication; there are no account-level ones

Everything a writer gathers or drafts lives in a publication (a publication's own notes and articles, its ideas, and each idea's drafts, notes and links). A person's landing page reads across their publications (drafts to pick up, quick add into a chosen publication) but holds nothing of its own, and there is no default-profile redirect. We rejected a personal, account-level space for ideas, notes and lists of articles because it would add a second owner to every store, route, permission check, navigation level and prompt (the AI reads the publication's description), and would raise the question of what happens when personal work is moved into a shared publication. Instead, things can be moved between publications the person belongs to (see #193 and #194), and quick add defaults to the publication last worked in.

The cost is that a writer with a stray thought must pick a publication, so a writer's first publication can be a personal one (the describe page already supports one described as "personal, mostly for me"). If that proves too much friction, revisit this before adding a second owner type.
