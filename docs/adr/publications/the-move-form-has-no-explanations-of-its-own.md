# The Move form: one row's Move, no toolbar for a single row, no explanations (#277)

- **A list with one row has no toolbar**, as there is nothing to select all of or act on in bulk, and the tick on that row
  goes too. A list that can be filtered keeps its toolbar (notes, when a tag is chosen), or the funnel would vanish with the
  one match.
- **Every note, article and idea has its own Move icon**, so a lone row can still be moved. It opens a dialog holding the same
  form as the toolbar's, and moves that row alone, whatever else is ticked.
- **The form explains nothing beyond how many it moves** (“Move 4 notes to”; the one-row dialog, whose title names the note or
  article, keeps “Move to”): no “moved, not copied”, no “keeps its tags”. The result shows in the destination and in the
  notice that follows (with Undo). The one line left is that the pages the notes were taken from are copied to the
  destination's articles, since that is a side effect the writer wouldn't guess; it is body text, not small print.
