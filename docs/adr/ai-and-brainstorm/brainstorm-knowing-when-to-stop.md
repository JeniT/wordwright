# Brainstorm: knowing when to stop (#46)

The coach is told to ask one question at a time and to say plainly when the idea is clear enough to draft
(`prompts/brainstorm-rules.md`). The writer can always move on to the next step ("Next: 05 Draft"; an earlier "I have
enough" link beside Send was removed in the Refine content crit, #283), so ending the session is a choice they can make
without waiting for the coach to say so. **No cap on questions per session.** The prompt and the writer's exit are
enough for now, and a count would need a decision on what resets it (as for critique looks, #103); revisit if real
sessions run on. The behaviour evals for this (says when ready, doesn't reopen when the writer stops, asks one
question) are in the `current` group.
