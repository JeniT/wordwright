# First real-model run of the evals: words first, no suggestions from the snapshot, titles as noun phrases (#304)

The first run against `claude-sonnet-5-5` after #303 passed 5 of 25: 15 failures were replies of tool calls with no words (the model took its tool calls as the whole turn), two were completely empty, and the quotation case passed 5 of 5. The adapter was ruled out (it streams text deltas and tool calls faithfully), so it is the model's habit, and a generic rule at the top of the rules did not beat it. The prompts now say the message comes first and tool calls after it, in the kickoff turn (nearest the generation) as well as the rules and tool prompts; that notes in the snapshot are the writer's already and are never suggested back, nor anything on an opening turn (the model had suggested a note copied from the idea's notes); and that a title is a noun phrase naming the subject, with an example, not a question (it had copied the idea's name as a headline-style question). If a re-run still returns tool calls alone, the next step is in the app: when a reply has tool calls and no words, send the tool results back and let the model write its message, with the evals mirroring that step. **Prompt changes (`brainstorm-kickoff.md`, `brainstorm-rules.md`, `tool-suggest-note.md`, `tool-name-conversation.md`): the owner reviews them and re-runs the evals.**
