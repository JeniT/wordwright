# Keep writing: one box for the drafts worth carrying on with (#310)

"Pick up" (Home, the three newest drafts) and "Reviews you sent" (a publication's page, every draft with a review request) were two doors into the same thing: a draft the writer is working on. Reviews are only one sign a draft is active, so they became one box, **Keep writing**, under Quick add on Home, a publication's landing page and an idea's. The writer rarely needs each review request's detail (the draft's Reviews tab has it), only whether reviews are finished and how many comments are unresolved, so a row says that once, totalled over all the draft's requests.

**Active** is saved in the last 30 days, or has a review in progress (reading, or an invitation not yet answered), or has comments the editor has not resolved. Drafts have no published state yet, so without a time limit the box would list every draft ever written and never hide. Unresolved comments come first, then newest. It starts at three and "Show more" appends three at a time, because nothing lists all drafts across a publication or the site, and the list should grow in place, not page. One endpoint, `GET /api/drafts/active`, replaced `/api/drafts/recent`; Quick add's publication picker now defaults to the publication of the first active draft instead of keeping a second endpoint alive for that. The offered and waiting drafts (Accept, Decline, Withdraw) stay in `PublicationAttention`: they are decisions, not drafts to carry on with.

The row is shared with the idea's Draft page, which now shows each draft's editor as a name chip, the person's own included. We name people everywhere in the app and never write "you" or an "Editor:" label; the chip is the one the notes already use for their author. Review wording changed with it: "2 of 5 reviews complete", where it used to say "2/5 complete", on the Reviews tab as well, so the two places read the same. Rejected: showing each request's line in the box (noise the draft page already has); moving published drafts to the bottom of the idea's list (the order is the reading order of a linked set). Marking a draft published, with an optional link, is #311.
