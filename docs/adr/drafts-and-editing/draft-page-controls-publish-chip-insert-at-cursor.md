# Draft page controls: the publish chip, Insert at cursor, and a typing tag filter (#342, #343)

- **Once a draft is published, the Publish section shows just the "Published" chip** (#342), as the row on the Draft page does;
  a box around it said the same thing twice. Once there is a link, its form folds away behind an edit button after "View post";
  with no link the form shows, since it is the only way to add one.
- **"Insert at cursor" (#343)** is the one name for putting a note or article into the draft, an icon button at the top of the
  drag rail. The rail is always drawn for someone who may edit (the button must work on a phone); only its grip is wide-screen.
- **The tag filter is a combobox, not a select.** It suggests the tags on that list not yet chosen; Return adds the active
  suggestion or an exactly typed tag. A tag nothing carries is refused with a message rather than creating a filter that can
  show nothing.
